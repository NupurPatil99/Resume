Technical showcase

CDS annotation lab.

Small, readable examples that show how CDS annotations influence Fiori experiences. These are illustrative patterns—not copied from a live customer system.

ABAP CDS · UI annotations
@EndUserText.label: 'Stocklist Items'
define view entity ZI_StocklistItem
  as select from zstocklist_item
{
  key material as Material,

  @UI.lineItem: [{ position: 10, importance: #HIGH }]
  @UI.selectionField: [{ position: 10 }]
  material,

  @UI.lineItem: [{ position: 20 }]
  plant,

  @UI.lineItem: [{ position: 30 }]
  season
}
Use UI.lineItem to define table columns and UI.selectionField to expose fields in a filter bar. Adjust syntax and data sources for your ABAP release and application model.

The examples below are learning snippets. Verify syntax against your ABAP release and model type before using them. Authorization annotations alone do not implement row-level access control; validate DCL roles and application authorization behavior as well.
